# SmartGrid KG — План разработки и выхода на рынок (от 0 до первого клиента)

**Продукт:** предиктивное API для оценки локальных перегрузок энергосети и риска отключений в Бишкеке. Реализованы сбор погоды, асинхронная БД и демонстрационный ML-пайплайн на синтетических нагрузках. Прогноз реальных аварий не подтверждён.

**Версия:** 0.2.0 · обновлено 2026-10-10.

## Правило ведения плана
- Завершённый и проверенный пункт: галочка и зачёркивание.
- Частично выполненный пункт остаётся открытым с пояснением.
- Каждый следующий ZIP проекта должен содержать актуальный plan.md в корне и CHANGELOG.md.
- Отметки синхронизировать со страницей плана в Notion при наличии доступа. Этот файл не запускает автоматизацию сам по себе.
